# 决策记录

所有数字均查于 2026-10-21，单位 CHF，单人，不含餐饮。

## 1. 日期：保留 3 月初

- 2027 年 3 月 8 日新月；2 月 20 日满月。3/5–3/11 整段无月光或只有傍晚就落下的细月牙（api.met.no，USNO）。
- 2026/27 冬季是强到极强的厄尔尼诺（NOAA CPC 2026-10-08：1–3 月持续概率 >83%）。MET Norway 和 NORCE 认为它对挪威北部的影响小且间接。按 seNorge 积雪模型，1958 年以来 10 个强厄尔尼诺冬季，罗弗敦 3 月初的积雪概率与平常年份相同。
- 罗弗敦海边有雪的天数：1991–2020 年约 80%，2011–2026 年约 60–70%。2 月底只比 3 月初略好，统计上不显著。
- 结论：保留 3 月初。不往后延，因为 3/13 起月亮整夜挂着，3/22 满月。

## 3. 斯瓦尔巴：不去

- 无团 3 晚约 505：机票 281 + 床位 188 + 机场大巴 13 + 博物馆 23。
- 三项体验约 1,000：狗拉雪橇 NOK 2,590–2,690、摩托追极光驾驶 NOK 2,750–2,900、种子库观光车 NOK 445。
- 海冰或冰缘游船 3 月不运营，最早 2027-04-15。
- 结论：这些体验在特罗姆瑟或罗瓦涅米也能做；镇上值得去的地方不多。这笔钱留给非洲、马丘比丘或南极。

## 4. 付费活动

狗拉雪橇、驯鹿、追光团都不默认参加。缆车保留（NOK 645）。冬季不走夏尔巴台阶（结冰，每年都有救援）。

## 5. A 对 C：选 C

- 两者现金几乎一样。A 多用 48,000 积分（按买分成本 CHF 49/万分，约 CHF 235）和 3 天假。
- 看到极光的概率粗估：C 约 65–75%，A 约 75–85%。这是个人估算，因为阴天常连续几天，各晚并不独立。
- 一次追光团（约 96–140）专门解决本地阴天，比多住 3 晚性价比高。
- C 的限制：周六晚的追光团必须在 00:30 前回城，因为 Havila 01:15 截止登船，大巴团写的是 23:00–02:00 回城。
